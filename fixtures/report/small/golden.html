  • Add a dead-letter queue to the ingest path
    f85d5c07 · $11.59 · 11.1M tokens · claude-opus-4-7
    Added a dead-letter queue so a record the parser rejects is parked with its failure reason instead of being retried forever behind the live stream. (#109, #110)
  • Wire the ingest retry backoff
    511c0e88 · $11.41 · 11.0M tokens · claude-opus-4-7
    Replaced the fixed retry delay with a bounded exponential backoff and a jitter window, so a downstream blip no longer arrives back as a synchronized retry storm. (#118)
  • Trace a cold start in the ingest worker
    7fa460c4 · $6.28 · 10.3M tokens · claude-sonnet-4-6
    Traced a cold start in the ingest worker to a synchronous hostname lookup on the request path, moved it behind a warmed cache, and added a regression test that fails when the lookup happens inside the handler. (#121, #122)
  • Audit the beacon retention policy
    47cff873 · $4.38 · 7.9M tokens · claude-sonnet-4-6
    Audited the retention policy against what the storage layer actually deletes, found two buckets the sweeper never visited, and wired them into the same scheduled job. (#106, #107)
  • Backfill the missing ingest metric labels
    cedee722 · $4.30 · 7.3M tokens · claude-sonnet-4-6
    Backfilled the missing labels on the ingest metrics so the per-tenant dashboard stops collapsing every tenant into one series. (#115)
